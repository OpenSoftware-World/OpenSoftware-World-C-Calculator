## OpenSoftware-World C-Calculator (For MikeOS and MikeOS-based OS.)

Note: This calculator software has been developed exclusively for MikeOS version 4.7.0 and later, as well as for operating systems based on the MikeOS platform.
Note1: If you want to recompile this program, download the MikeOS C-Lib library using the link “https://mikeos.sourceforge.net/libmikeos-4.2.tar.gz”.
